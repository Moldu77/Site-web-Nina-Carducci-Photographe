# 📸 Nina Carducci – Débogage et optimisation d'un site de photographe

🌐 **Site en ligne :** https://moldu77.github.io/Site-web-Nina-Carducci-Photographe/

🇫🇷 Français · 🇬🇧 [English](#-english)

## Contexte

Projet réalisé dans le cadre de la formation **Développeur Web d'OpenClassrooms**.
Nina Carducci, photographe, souhaitait améliorer le référencement et les performances de son site portfolio. Ma mission : auditer le site existant, corriger ses bugs, l'optimiser, puis rendre compte de l'intervention à la cliente.

## Ce que j'ai fait

- **Audit** du site avec Lighthouse (performances, accessibilité, bonnes pratiques, SEO)
- **Débogage** de la galerie photo (plugin mauGallery) : navigation entre les images
- **Performances** : images converties en WebP et déclinées en plusieurs tailles, nettoyage du code
- **Accessibilité** : labels et attributs des formulaires, contrôles du carrousel, couleurs des liens et boutons
- **SEO** : balises meta, titre et description, Open Graph et Twitter Card pour le partage sur les réseaux sociaux
- **Rapport d'intervention** rédigé pour la cliente, avec un comparatif avant / après

## Technologies

HTML5 · CSS3 · JavaScript · Bootstrap · Lighthouse · GitHub Pages

## Lancer le projet en local

```bash
git clone https://github.com/Moldu77/Site-web-Nina-Carducci-Photographe.git
```
